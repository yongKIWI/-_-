사이트 문구 정리 변경 내역
작성일: 2026.10.28

1. 작업 목적
설명형 제목·반복 성과·추상적인 자기평가를 줄이고, 제목만 훑어도 업무를 파악할 수 있도록 정리했습니다.
핵심 수치와 근거를 지우지 않고, 제목·요약·본문의 역할을 나눴습니다.
새 펼침 항목으로 글을 숨기는 방식이 아니라 문장 자체의 분량을 줄였습니다.
이력서·자소서 파일은 이번 작업 범위에 포함하지 않았습니다.

2. 분량 비교
본문 기본 노출 상태, PC 1440px 기준. 공백·수정필요 표시는 제외했습니다.
- 메인: 1,846자 → 1,435자 (약 22.3% 감소)
- 퍼포먼스 관점: 1,874자 → 1,436자 (약 23.4% 감소)
- 제작 통합앱: 1,579자 → 1,154자 (약 26.9% 감소)
- 콘텐츠 SEO: 2,349자 → 1,862자 (약 20.7% 감소)
- 순위 조사: 1,361자 → 1,089자 (약 20.0% 감소)
- 업무 도구: 1,666자 → 1,257자 (약 24.5% 감소)

사이트 TS/TSX의 한국어 문구 원문(숨김 설명·접근성 문구·공유 메타데이터 포함):
14,791자 → 11,201자, 약 24.3% 감소.
원문 집계와 화면 노출 집계는 범위가 달라 직접 비교하지 않습니다.

3. 핵심 변경
- 첫 화면: 긴 업무 선언을 짧은 소개로 변경.
  기존: 업체와 콘텐츠 방향을 정하고, 제작부터 성과 개선까지 맡는 AE 이용택입니다.
  변경: 콘텐츠 기획부터 제작과 성과 개선까지, AE 이용택입니다.
  수정필요 3 유지.

- 메인 제목: ‘반복 작업은 줄이고, 실제 운영량과 검색 성과를 높였습니다’ → ‘제작 효율과 검색 성과’.
- 프로젝트 제목: 설명 문장 대신 제작 자동화·SEO·순위 조사·업무 도구를 식별하는 제목으로 변경.
- 소개·문제·결과에서 같은 숫자를 반복하는 문장을 축약. 수치 카드와 전후 비교표는 유지.
- 고객 제안 사례: 요청·조정한 내용·확인한 결과를 짧게 구분. 매출/플레이스 기여 미확인 범위 유지.
- 경력·대외활동: 역할·기여 범위·수상·실제 게시 결과 중심으로 정리.
- ‘일하는 방식’: 태도 선언을 줄이고 별도 지시 없이 개선을 시작한 배경을 간결하게 유지.
- ‘배운 점’: 추상적인 교훈 대신 업체별 설정·판정 기준·보고 자동화·오류 복구 등 실무에 남긴 기준으로 변경.
- 연락처: 포부 문장 대신 이름·채용 문의 안내.
- 공유 이미지·검색 메타데이터의 제목과 설명도 함께 정리.
- 문장이 필요한 판단·행동 설명은 ‘~했습니다’를 유지. 모두 명사형이나 전문용어로 치환하지 않음.

4. 보존한 중요 내용
- 기존 검토 번호 252개 모두 유지. 재번호·삭제·종료 번호 재사용 없음.
- 90건 약 4시간 수작업 → 약 30분 무인 제작·검수, 설정 5~10분 별도.
- 2~3명 → 1명, 20~30개 → 50~60개 업체, 월 약 2,000건 → 약 8,200건 실제 운영.
- 제작 중 다른 업무 수행, 업체별 설정·요청·클레임 대응, 촬영팀·외부 실행사 조율.
- 실수요 키워드 TOP 7 진입률 약 1~5% → 40~60%, 월 발행 실수요 키워드 기준.
- 전체 업체 주간 최대 7,248개, 단일 업체 최대 248개.
- 검색량 확인용 자체 API 도구와 경쟁도 분석용 상용 솔루션의 역할 구분.
- 키워드 선별과 콘텐츠 A/B 테스트의 구분, 여러 실험 중 세 후속 사례라는 범위.
- 실험 표본·통제 조건·41/120 대 76/120, 64/120 대 66/120, 212/500 대 367/500·채택/롤백.
- 공통 4주간 주 1회 관찰, 순차 발행과 통계 해석의 한계.
- 스마트블록 활용 제안과 이후 축소 대응을 별개 사례로 구분.
- 수작업 2~3명·6~7시간, 전주 목·금 준비 이력.
- 초기 자동화 PC 2대·8,000건·6시간, 현재 PC 1대·약 1.4만 건·5~6시간.
- 2025.10 도입 이후 본인 야근 주 3~4회 → 0회.
- 사진 활용 약 5개월·최대 7~8개월, 외주 촬영 중단과 사내 촬영 유지 구분.
- 리뷰 수 60개 이상 업체·약 30초, 기본 사용 안내 약 20분.
- 대덕넷 인턴, 학력, KOSAC 2회, KOBACO 팀 제작·게시, GA4 취득 이력.
- 그래프 원본 수치, 캡처 경로·설명 범위, 링크·분석 기능 유지.

5. 검증
- Next.js 배포용 빌드·TypeScript 검사 통과.
- 6개 페이지 PC 1440px, 모바일 390/320px에서 가로 넘침 없음 확인.
- 수정 전후 코드 비교로 검토 번호·핵심 지표·전후 비교값·실험값·그래프값·이미지 연결 동일 확인.
- 기존 D: 작업본과 수정 전 기준 파일 일치 확인 후 동기화.
- 수정 전 원본은 Git 이력 및 별도 백업에 보존.
