포트폴리오 불필요한 해명 문구 정리
작성일: 2026.10.29

1. 수정 범위
- 홈과 상세 4개 페이지의 문구를 점검했다.
- lib/site-data.ts의 10개 문자열과 상세 하단 공통 안내 문단 1곳을 정리했다.
- 페이지 구조, 섹션 순서, 메뉴, 링크, 접기·펼치기, CSS는 수정하지 않았다.
- 이력서·자기소개서 파일은 수정하지 않았다.

2. 바꾼 내용

[상세 4페이지 공통 / 하단 안내]
삭제: 화면은 실제 업무 자료를 기반으로 하며, 공개 범위에 맞춰 필요한 항목은 익명화하거나 재구성합니다.
이유: 자료 편집 방침에 관한 내부 메모로, 성과 설명과 무관하다. 문단만 제거했으며 섹션·목차·기능·스타일은 변경하지 않았다. 캡처 자체나 공개 범위를 바꾼 작업은 아니다.

[제작 통합앱 / 업체 제안 결과 / 수정필요 264]
이전: 관련 검색 노출과 업체의 긍정적 반응을 확인했습니다. 매출 증가액은 확인하지 않았습니다.
변경: 관련 검색 노출과 업체의 긍정적 반응을 확인했습니다.
이유: 매출 증가를 성과로 주장하지 않으므로 미확인 사실까지 덧붙일 필요가 없다. 264번은 그대로 유지했다.

[제작 통합앱 / 측정 기준]
이전: 월 약 8,200건은 최대 처리량이 아닌 실제 제작·배포 관리량입니다.
변경: 월 약 8,200건은 실제 제작·배포 관리량입니다.
이유: 실제 운영량이라는 정의만으로 의미가 충분하다.

이전: 규칙 검사·API 보정·재검사로 건별 수동 검수를 대체했으며, 출력 정확성 100%를 뜻하지 않습니다.
변경: 규칙 검사·API 보정·재검사로 건별 수동 검수를 대체했습니다.
이유: 검수 방식을 설명하되, 주장하지 않은 100% 정확도를 선제 부정하지 않는다. 도입 전 샘플 검토와 검수 절차는 유지했다.

[통합앱 기본 화면 캡션 / 제작 통합앱·보조 자동화 각 1곳]
이전: 업체 정보가 포함되지 않은 실제 기본 화면 · …
변경: 실제 기본 화면 · …
이유: 업무 기능 설명과 무관한 데이터 포함 여부 안내를 뺐다. 화면과 기존 기능 설명은 유지했다.

[키워드 순위 조사 / 실행 캡처]
제목: 이전 버전의 대량 조사 실행 화면 → 대량 조사 실행 화면
설명: 이전 버전의 진행률·처리량·순위 확인 화면. 현재 C#·WPF·Chrome CDP 버전의 성능과 구분합니다.
→ 진행률·처리량·순위 확보 현황을 확인하는 실행 화면.
이유: 이전 버전임은 바로 아래 캡션에 이미 표시되어 있다. 캡션의 ‘이전 버전 실행 화면 · 처리 428 / 6,425건’은 그대로 유지했다.

[키워드 순위 조사 / 보고 결과 캡처]
이전: 이전 버전의 Excel 보고 결과. 현재도 TOP 7 결과의 보고 문장을 자동 출력합니다.
변경: 키워드·업체명·순위와 TOP 7 보고 문장을 정리한 Excel 결과.
이유: 보고서에 무엇이 들어가는지 설명한다. ‘이전 버전의 실제 자동 보고 결과’ 캡션은 그대로 유지했다.

[키워드 순위 조사 / 누적 조사량 산식]
이전: 과거 10개월 누적 조사량… 현재 성능을 소급 적용하지 않습니다.
변경: 도입 후 10개월 누적 조사량은 당시 1회 평균 약 9,500건 × 월 5~6회 × 10개월로 약 47.5만~57만 회(대표값 약 52만 회) 추정입니다.
이유: 과거 평균과 기간을 산식에서 직접 밝힌다. ‘현재 성능을 소급하지 않는다’는 해명을 덧붙이지 않는다.
유지: 동일 키워드 재조사 포함, 조사 건수와 실제 검색 요청 수 차이, 시간 초과·검색 제한 시 일시정지 후 확인·재개.

[보조 자동화 / 리뷰 모니터링 캡션]
이전: 실제 실행 완료 화면 · 42개 플레이스 리뷰 수 자동 조회
변경: 이전 실행 화면 · 42개 플레이스 리뷰 수 자동 조회
이유: 과거 실행 기록이라는 출처 정보를 이미지 옆에 짧게 둔다. 42개 수치는 바꾸지 않았다.
