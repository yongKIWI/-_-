AE 단일 포트폴리오 및 사례 중심 구성 변경
작성일: 2026.10.28

1. 공개 소개 통일
- 기획 관점 / 퍼포먼스 관점 전환과 하단 직무별 링크를 제거했습니다.
- 소개를 ‘콘텐츠 기획부터 제작과 성과 개선까지, AE 이용택입니다.’로 통합했습니다.
- 업체와의 협의, 제작·분석 도구 직접 기획·개발, 운영과 성과 개선을 한 문장에 연결했습니다.
- 기존 두 주소는 홈으로 연결하고 유입 추적 쿼리를 전달합니다.
- 탭 제목, 공유 이미지, 구조화 정보와 사이트맵도 단일 AE 소개에 맞췄습니다.
- 기존 공유 이미지 URL은 깨뜨리지 않고 동일한 AE 이미지로 제공합니다.

2. 중복 축소
- 서로 다른 관점 화면에서 반복되던 소개·성과 정의를 하나로 합쳤습니다.
- 통합앱의 문제 판단과 사례 소개에서 반복되던 자동화 우선순위 설명을 합쳤습니다.
- 같은 내용으로 합쳐진 검토 번호는 한 문구에 함께 표시했습니다.

3. 보조 자동화의 실제 사례 우선
- 비대상 URL이 순위 결과에 섞인 경우: 발생 조건 확인 → URL 제외 규칙 추가 → 표본 재검증.
- 장시간 실행이 중단된 경우: 간격·대기·재시도·오류 복구 적용 → 확인 후 해당 키워드부터 재개.
- 6단계 점검 절차와 공통 도구 기획·구현 과정은 펼쳐 읽는 보조 설명으로 이동했습니다.
- 이미지 처리와 모니터링의 기존 성과·증거 자료·수치는 유지했습니다.

4. SEO의 정보 우선순위
- 실수요 키워드 진입률 1~5% → 40~60%를 상단 주 지표로 강조했습니다.
- 주간 최대 7,248개, 단일 업체 최대 248개, 1회 자동 조사량은 보조 지표로 낮췄습니다. 수치는 삭제하지 않았습니다.
- 진입률 바로 아래에서 실험 결과로 이동할 수 있습니다.
- 실험 카드를 공통 측정 방식보다 앞에 배치했습니다.
- 비교안별 표본·통제 조건·비율·차이·채택/롤백을 기본 노출합니다. 상세 가설과 측정 방식은 펼쳐 확인할 수 있습니다.
- 전체 운영 진입률과 개별 실험의 누적 관찰 비율은 구분했습니다. 세 실험을 전체 실험 건수로 표현하지 않습니다.

5. 보존 내역
- 기존 수정필요 번호 252개를 그대로 유지했습니다.
- 각 프로젝트 핵심 지표, 전후 비교 수치, 초기/현재 자동화 성능, 실험별 표본과 결과, 추적 그래프, 증거 이미지, 도구와 기여 범위는 유지했습니다.
- 새 성과·매출·유료 매체 집행 경험을 만들어 넣지 않았습니다.
- 이력서·자기소개서 파일은 수정하지 않았습니다.

236·240: SEO 공유 이미지 지표 라벨

7. 판단 근거
- 같은 성과를 다른 순서로 보여주는 두 화면은 방문자에게 추가 선택과 중복 확인을 요구합니다.
- 단일 AE 소개 아래에서 기획·운영·분석 역량이 연결되도록 하는 편이 현재 자료의 강점을 이해하기 쉽습니다.
- 두 관점이 있었다는 이유만으로 지원 진정성이 없다고 단정하지는 않습니다.
- 명칭 통일이 지원 직무별 경험 차이를 없애는 것은 아닙니다. 지원 회사별 강조점은 이력서·지원동기에서 조정하는 것이 적절합니다.
