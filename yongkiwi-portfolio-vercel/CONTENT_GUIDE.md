# 콘텐츠 수정 가이드

이 사이트는 텍스트와 핵심 성과를 한곳에서 쉽게 관리할 수 있도록 구성했습니다.

## 핵심 성과와 프로젝트 수정

- 공통 성과, 경력, 프로젝트 상세 내용: `lib/site-data.ts`
- 광고기획·퍼포먼스 AE 첫 화면 문구: `components/PortfolioPage.tsx`
- 연락 이메일: `components/PortfolioPage.tsx`에서 `tag.y603@gmail.com` 검색

수치를 수정할 때는 같은 숫자가 여러 영역에 사용되는지 전체 검색으로 확인하세요. 특히 `약`, `평균`, `추정` 표현을 삭제하지 마세요.

## 프로젝트 추가

1. `lib/site-data.ts`의 `projects` 배열에서 기존 프로젝트 형식을 복사합니다.
2. 중복되지 않는 영문 `slug`를 입력합니다.
3. `components/PortfolioPage.tsx`의 `projectOrder`에 slug를 추가합니다.
4. `npm run build`로 오류를 확인합니다.

## 이력서 PDF 추가

직무별 PDF가 완성되면 `public/resume` 폴더를 만들고 아래 이름으로 저장하세요.

- `lee-yongtaek-advertising-ae.pdf`
- `lee-yongtaek-performance-ae.pdf`

현재 사이트는 오래된 PDF를 잘못 연결하지 않기 위해 이력서 다운로드 버튼을 표시하지 않습니다.

## 이미지 추가

고객사명, 계정, 실제 키워드와 내부 주소를 제거한 뒤 `public/images/projects` 아래에 프로젝트별로 저장하세요.

실제 화면을 단순히 흐리게 처리하기보다 가상의 업체명과 샘플 데이터로 재구성하는 방식을 권장합니다.

## 반드시 지켜야 할 표현

- 순위 조사: 평균 약 9,500건, 약 4시간 무인 실행
- 누적 조사: 10개월간 약 52만 건
- 통합검색 1~7위 진입률: 키워드 검색 시 우리 콘텐츠가 전체 콘텐츠 중 1~7위에 나타난 비율, 30~40% → 70~80%
- 제작 방식: 90건 4시간 수작업 → 약 50분 무인 자동 실행
- 촬영비 절감 수치는 반드시 `추정`으로 표시

`반나절 → 10분`, `전사 사용`, 확인되지 않은 ROAS·CPA·매출 수치는 사용하지 않습니다.
