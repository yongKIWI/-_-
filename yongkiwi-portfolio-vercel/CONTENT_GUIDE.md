# 콘텐츠 수정 가이드

이 사이트는 텍스트와 핵심 성과를 한곳에서 쉽게 관리할 수 있도록 구성했습니다.

## 핵심 성과와 프로젝트 수정

- 공통 성과, 경력, 프로젝트 상세 내용: `lib/site-data.ts`
- 광고기획·퍼포먼스 AE 첫 화면 문구: `components/PortfolioPage.tsx`
- 연락 이메일: `components/ContactEmail.tsx`

수치를 수정할 때는 같은 숫자가 여러 영역에 사용되는지 전체 검색으로 확인하세요. 특히 `약`, `평균`, `추정` 표현을 삭제하지 마세요.

## 문체 원칙

- `성과·구조·체계·운영·실제·직접` 같은 추상적인 단어를 한 문단에서 반복하지 않습니다.
- 문제를 발견한 이유, 직접 한 행동, 달라진 결과가 한 번에 보이도록 씁니다.
- `오너십으로 기여`, `성과가 반복되는 구조`처럼 채용 문서에서 흔한 표현보다 실제 행동을 설명합니다.
- 전문용어는 필요한 곳에만 사용하고, 먼저 쉬운 말로 의미를 설명합니다.
- 프로그램 구현 과정은 `생성형 AI 기반 개발 도구`라고 뭉뚱그리지 않고 사실에 맞게 `Codex를 활용해 구현`으로 표현합니다.

## 문구 검토 번호

- `(수정필요 1)`~`(수정필요 260)`은 문구별 고정 식별자입니다. 수정하더라도 기존 번호를 유지하고, 전체를 다시 번호 매기지 않습니다.
- 같은 데이터나 공통 컴포넌트가 여러 화면에 나타나면 같은 번호를 공유합니다. 해당 번호를 수정하면 연결된 화면에도 반영됩니다.
- 유지·수정한 문구의 번호는 그대로 둡니다. `유지`, `삭제`, `교체할 문구`를 번호별로 요청할 수 있습니다. 중복 통합으로 빠진 번호는 아래 대응표에 기록하고 다시 사용하지 않습니다.
- 키워드 선별과 콘텐츠 A/B 테스트를 구분하고, 1,480건은 세 실험의 콘텐츠 발행량에만 사용합니다.
- 기간과 누적량은 기록 기준으로 유지하며 날짜가 지났다는 이유로 자동 증가시키지 않습니다.

## 경력과 기획 경험의 배치

- 메인 순서는 핵심 성과 → 대표 프로젝트 → 경력·관련 경험 → 일하는 방식 → 업무 도구입니다. 상단 메뉴 순서도 실제 섹션 순서를 따릅니다.
- 웨이팅리스트 대표 카드와 프로젝트 상세는 유지합니다. 이전 경험을 같은 분량의 프로젝트로 확장하지 않습니다.
- 대덕넷은 행사 기획·운영을 지원한 인턴 경력으로, KOSAC은 캠페인 기획 역할로, KOBACO는 팀 광고 제작 경험으로 설명합니다. 행사 총괄이나 확인되지 않은 협업 갈등 해결 사례를 추가하지 않습니다.
- 웨이팅리스트의 기획 경험은 업체와 콘텐츠 방향 협의 → 제작 기준 설계 → 자동 실행 → 수정 반영으로 설명합니다. 업체 소통을 내부 팀 협업 실적으로 확대하지 않습니다.
- 2026.09.09 구성 정리로 기존 1~250번은 그대로 두고, 새로 다듬은 무번호 설명에 251~260번을 추가했습니다.
- 251: 웨이팅리스트 경력 요약 / 252: 대덕넷 경력 요약 / 253: KOSAC 역할 / 254: KOBACO 경험
- 255~258: 제작 통합앱의 협의·설계·실행·수정 설명 / 259: 업체 방향에 맞춘 키워드 리서치 / 260: 대덕넷 인턴 역할 표기

## 2026.09.09 설명 통합과 성과 배치

- 제작 통합앱은 제작·검수 자동화, 업체별 요구 반영, 실제 월 운영량을 설명합니다. 야근 해소의 직접적인 계기는 순위 조사·보고 프로그램 도입이므로 해당 성과는 순위 프로젝트에 배치합니다.
- 통합앱의 분석·실행은 방향 협의 → 제작 방식 설계 → 자동 실행 → 수정 반영의 4단계로 설명합니다. 같은 과정을 별도의 8단계 목록으로 반복하지 않습니다.
- SEO 프로젝트는 키워드 리서치, 콘텐츠 실험과 검색 노출 변화 대응을 담당합니다. 스마트블록 축소에 따른 선별 기준 변경 및 관련 주간 브리핑도 이곳에 둡니다.
- 업무 도구 프로젝트는 이미지 처리·모니터링과 프로그램의 기술적 유지보수에 집중합니다. 콘텐츠 A/B 테스트를 다시 설명하지 않습니다.
- 각 프로젝트의 `featuredProofIndex`는 초반에 보여줄 기존 자료의 번호입니다(0부터 시작). 선정된 자료는 하단에서 중복 표시하지 않습니다. 나머지 자료는 성과 다음에 유지합니다.
- 메인에서는 순위 자동화 도입 후 야근 해소를 보여주고, 추정 누적 조사량은 순위 프로젝트의 측정 기준에 남깁니다. 약 20분 기본 사용법 안내는 도구 상세에서 설명합니다.
- 기존 1~260번 중 244개 번호가 2026.09.09 정리 당시 문구에 남아 있었습니다. 아래 16개는 중복 통합으로 사용을 종료했으며, 다른 문구에 재배정하지 않습니다.

종료한 번호 → 내용을 이어받은 번호

- 38 → 180·208: 약 20분 기본 사용법 안내를 메인에서 도구 상세로 모음.

- 검색 노출은 클릭·문의·매출·ROAS와 다르다. 플레이스 기여는 입증되지 않았으며 별도 담당자의 업무를 본인에게 귀속하지 않는다.
