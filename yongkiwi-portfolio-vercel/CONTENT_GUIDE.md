# 콘텐츠 수정 가이드

이 사이트는 텍스트와 핵심 성과를 한곳에서 쉽게 관리할 수 있도록 구성했습니다.

## 핵심 성과와 프로젝트 수정

- 공통 성과, 경력, 프로젝트 상세 내용: `lib/site-data.ts`
- 광고기획·퍼포먼스 AE 첫 화면 문구: `components/PortfolioPage.tsx`
- 연락 이메일: `components/PortfolioPage.tsx`에서 `tag.y603@gmail.com` 검색

수치를 수정할 때는 같은 숫자가 여러 영역에 사용되는지 전체 검색으로 확인하세요. 특히 `약`, `평균`, `추정` 표현을 삭제하지 마세요.

## 프로젝트 추가

1. `lib/site-data.ts`의 `projects` 배열에서 기존 프로젝트 형식을 복사합니다.
2. 중복되지 않는 영문 `slug`를 입력합니다.
3. `components/PortfolioPage.tsx`의 `projectOrder`에 slug를 추가합니다.
4. `npm run build`로 오류를 확인합니다.

## 이력서 PDF 추가

직무별 PDF가 완성되면 `public/resume` 폴더를 만들고 아래 이름으로 저장하세요.

- `lee-yongtaek-advertising-ae.pdf`
- `lee-yongtaek-performance-ae.pdf`

현재 사이트는 오래된 PDF를 잘못 연결하지 않기 위해 이력서 다운로드 버튼을 표시하지 않습니다.

## 이미지 추가

고객사명, 계정, 실제 키워드와 내부 주소를 제거한 뒤 `public/images/projects` 아래에 프로젝트별로 저장하세요.

실제 화면을 단순히 흐리게 처리하기보다 가상의 업체명과 샘플 데이터로 재구성하는 방식을 권장합니다.

현재 `public/evidence/rank-monitoring-running.png`는 사용자가 실제 정보가 보이는 상태의 임시 공개를 승인한 순위 확인 프로그램 작동 화면입니다. 추후 샘플 데이터 버전이 준비되면 같은 파일명으로 교체합니다.

## 반드시 지켜야 할 표현

- 순위 조사: 평균 약 9,500건, 약 4시간 무인 실행
- 누적 조사: 10개월간 약 52만 건
- 키워드 성과 추적: 2025년 11월~2026년 8월, 현재 1회 자동 조사량 1만~1.2만 건, 전체 고객사 합산 TOP 7 키워드 최대 7,248개, 단일 고객사 최대 248개
- 네이버 통합검색 콘텐츠 TOP 7 진입률: 측정 대상 키워드 검색 결과에서 자사 콘텐츠가 콘텐츠 영역 상위 7개 결과 안에 진입한 비율, 30~40% → 70~80%
- SEO 표현 범위: 검색량·경쟁도 기반 키워드 리서치, 상위 검색결과(SERP) 분석, 콘텐츠 최적화, 순위 측정과 검색 로직 변화 대응을 묶어 `네이버 콘텐츠 SEO`로 설명한다. 웹사이트 크롤링·인덱싱·Core Web Vitals 등의 기술 SEO까지 수행한 것으로 확대하지 않는다.
- 제작 방식: 90건 4시간 수작업 → 약 50분 무인 자동 실행
- 운영 시스템: 2025년 10월 실사용 가능한 형태로 배포 후 10개월간 안정 운영
- 클라이언트 오너십: 50~60개 고객사를 담당하며 업체 대표와 콘텐츠 방향, 업종별·시즌별 키워드, 세부 요구사항을 직접 협의하고 수정·클레임까지 블로그 운영 전반에 대응
- 선별 배경: 한남대학교 광고홍보학 전공·정치언론학 복수전공, KOSAC 챌린지상 2회, KOBACO 옥외광고 실무과정 우수작, GAIQ만 사이트에 노출하고 그 외 대외활동은 이력서에서 관리
- 기술적 변경 대응: 키워드 순위·모니터링·이미지 도구는 대부분 당일, 범위가 큰 변경은 3일 이내 정상화
- 블로그 노출 로직 대응: 성과 하락 감지 후 1주 이내 콘텐츠 규칙 수정, 수정본 순차 발행 후 회복 추이 확인
- 콘텐츠 A/B 테스트: 키워드 선별 실험이 아니라 이미지 수·원고 엔진·소제목 등 콘텐츠 변수를 비교한 수차례 실험 중 대표 사례 3건. 해당 3건에 한해 A·B 각 120~500건, 콘텐츠 변형안 합계 1,480건을 발행한 뒤 4주 누적 TOP 7 진입률 비교. 3건·1,480건을 전체 실험 횟수나 전체 키워드 수로 표현하지 않는다.
- 대표 실험 결과: 이미지 10장 34.2% vs 15장 63.3% 채택, 기존 원고 엔진 42.4% vs 자연스러움 중심 엔진 73.4% 채택, 소제목·인용구 적용 53.3% vs 55.0%로 롤백
- A/B 측정 기준: 각 변형안에 사용한 모든 키워드를 주 1회씩 4주간 개별 추적. 4주 중 1회 이상 자사 콘텐츠가 통합검색 콘텐츠 TOP 7에 진입한 키워드를 1건으로 집계

- 30~40% → 70~80%는 키워드 선별만의 성과로 단정하지 않는다. 키워드 전략, 콘텐츠 변수 실험, 순위 측정, 플랫폼 변화 대응을 결합한 전체 운영 개선 성과로 설명한다.
- 6월 원고 엔진 테스트: 4개 업체 참여, 결과 확인 직후 자연스러움 중심 엔진을 프로그램 기본값과 사용법에 반영
- 프로그램 작동 문제: A/B 테스트로 표현하지 않고 이상 징후 확인 → 근본 원인 특정 → 로직 수정 → 수정 전후 재검증 → 재발 방지로 표현
- 촬영비 절감 수치는 반드시 `추정`으로 표시

`반나절 → 10분`, `전사 사용`, 확인되지 않은 A/B 개선 수치·통계적 유의성·ROAS·CPA·매출 수치는 사용하지 않습니다.
