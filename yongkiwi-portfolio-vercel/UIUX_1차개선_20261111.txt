UI/UX 1차 개선 — 2026.11.11

적용 범위
1. 홈 핵심 성과와 대표 프로젝트를 하나의 목록으로 통합.
   - 통합앱: 4시간 → 약 30분, 월 약 8,200건을 해당 프로젝트 안에서 표시.
   - SEO: 실수요 키워드 TOP 7 진입률 1~5% → 40~60% 유지.
   - 순위 조사: 본인 야근 주 3~4회 → 0회 유지.
   - 홈 메뉴는 성과·프로젝트로 통합. #impact / #projects 모두 보존.
2. 일반 제목은 줄이고 실제 결과 수치가 더 먼저 보이도록 글자 위계 조정.
   - PC 메인 제목 최대 48px, 일반 섹션 최대 32px.
   - 모바일 메인 32px, 섹션 25px, 본문 기본 16px.
   - 설명의 과한 굵기와 좁은 자간 완화. Pretendard와 기존 색상 유지.
3. 모바일 프로젝트 목차를 한 줄 버튼 + 세로 펼침 목록으로 변경.
   - 목차 자체 115px → 52px.
   - 상단 헤더 포함 고정 영역 약 181px → 118px.
   - Escape, 바깥 클릭, 항목 선택, 포커스 이탈 시 닫힘.
   - 접힌 측정 기준으로 이동 시 자동 펼침과 포커스 이동.
4. 실험 결과·채택/롤백 이유·가설과 주요 의사결정 단계를 기본 노출.
   - SEO details 요소 15개 → 8개, 통합앱 8개 → 4개.
   - 측정 산식·비교 조건·보조 자료·상세 운영 절차는 보존.
5. 반복되는 박스·그림자 정리. 다음 프로젝트·연락처·맨 위로 장식 축소.
   - 클릭 영역·이메일 복사·맨 위로 기능 유지.
   - 모바일 하단 버튼과 푸터의 여유 공간 유지.
6. 검정 영역의 키보드 포커스를 밝은 키위색으로 변경.
   - 검정 배경 대비 약 2.12:1 → 10.70:1.

- 검증한 30개 페이지·화면 조합에서 문서 가로 넘침 없음.
- 모바일 목차 닫기, 키보드 Escape, 측정 앵커 자동 펼침 확인.

적용 후 판단
- 홈에서 같은 성과를 요약 카드와 프로젝트 목록으로 두 번 읽는 부담이 줄었다.
- 실험 이유와 실제 결정은 클릭 없이 읽을 수 있다.
- SEO 상세는 기본 노출 정보가 늘었으므로 여전히 가장 긴 페이지다.
  핵심 실험을 숨기기보다, 추후 필요 시 대표 실험 중심의 별도 편집을 검토한다.
- 보조 자동화의 역할·운영 기간과 결과를 같은 지표 줄에 두는 구성은 후속 개선 후보.
  이번에는 공통 구조를 추가 개편하지 않고 사실·내용을 유지했다.
- 미완성 표시, 사진 교체, 이력서 연결은 평가 대상에서 제외했다.
